# AI DevOps Tooling — Memória Mestre

## Classificação
Projeto lógico de ferramentas auxiliares de organização, build, automação e controlo DevOps. Relacionado com DGM-MAT, mas não absorvido automaticamente pelo Core.

## Repositórios
- ai-devops-control-center — centro privado de governance, discovery, health e sync de repositórios.
- Jules-Multi-Agent-Devops — hub multi-agent GitHub-native, com brain local e satellite cloud/mobile.
- Project-Organizer-AI — candidato a organizador de projetos; conteúdo atual insuficiente para integração.
- build-control-center — painel web para builds, workflows e artefactos.
- build-control-panel — variante/companheiro do Build Control Center.
- universal-build-platform — candidato a plataforma universal de build; conteúdo ainda insuficiente.
- GitHub-auto-builder — aplicação Android para capturar código de IA e commitar no GitHub.

## Relação com DGM-MAT
São fontes/companheiros potenciais. Não importar código para DGM-MAT sem auditoria de interfaces e sem decisão arquitetural explícita.

## Próximo gate
Auditar implementações reais e sobreposição funcional antes de fundir repos ou mover código.
