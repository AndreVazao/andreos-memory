# VocalClaw — Memória Mestre

## Classificação
Projeto independente de Voice AI, originado num buildathon.

## Produto
Sistema multi-agent de voz com quatro agentes especializados, ElevenLabs para voz, Groq para inferência e modos Solo/Council.

## Relação
Potencial fonte de pesquisa para voz e agentes no ecossistema VAZÃO/Baribudos, mas não é dependência de produção.
