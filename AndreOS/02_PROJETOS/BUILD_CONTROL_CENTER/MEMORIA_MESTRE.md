# BUILD CONTROL CENTER - MEMÓRIA MESTRE

## Objetivo
Dashboard online para controlar builds de repositórios GitHub, detetar stacks, lançar GitHub Actions, acompanhar progresso e disponibilizar artefactos para download.

## Funcionalidades principais
- Listar repos privados e públicos acessíveis.
- Selecionar projetos para build.
- Detetar Node, Python, Android/Gradle e outros stacks.
- Mostrar estado: nunca built, atualizado, outdated, em progresso, falhou.
- Gerar links para artefactos.
- Integrar com GitHub Actions e Vercel quando aplicável.

## Próximo foco
Consolidar deteção de stacks, workflows universais e painel visual com progresso por repo.
