# Script Comparator — Decisões

## D01 — núcleo sem GUI
O módulo não depende de PyQt para poder ser reutilizado.

## D02 — extensão faz parte da identidade
`main.py` e `main.js` nunca são versões do mesmo ficheiro.

## D03 — nome canónico
O nome sem sufixo numérico representa o resultado consolidado.

## D04 — originais preservados
As versões de origem ficam numeradas; não são apagadas pelo merge.

## D05 — backup obrigatório
Renomeações e escritas devem ter backup antes da alteração.

## D06 — conflito é resultado válido
Um conflito deve ser exposto ao programa anfitrião para decisão.

## D07 — segurança > automação
Nunca aplicar alterações destrutivas só porque uma versão tem mais linhas.

## D08 — evolução
Adicionar adapters específicos para TypeScript/JavaScript, Kotlin/Java/C#, HTML/CSS e parsers mais profundos.
