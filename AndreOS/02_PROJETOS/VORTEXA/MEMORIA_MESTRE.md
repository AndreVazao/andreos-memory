# VORTEXA Core — Memória Mestre

## Classificação
Projeto independente de infraestrutura local para criação de personagens digitais, vozes, áudio e vídeo.

## Componentes
Core, system, database, auth, character studio, animation engine, media lab, API, dashboard e launcher.

## Relação
Tem forte proximidade temática com Baribudos Studio, mas deve permanecer separado até existir uma decisão explícita de integração/reutilização.
