# Segurança e Permissões

## Proibido guardar
- Passwords
- Tokens
- Chaves API
- Cookies
- Chaves privadas
- Credenciais de clientes
- Dados bancários sensíveis

## Ações que exigem aprovação
- Apagar ficheiros
- Alterar ficheiros críticos
- Criar commits
- Fazer push
- Criar ou apagar repositórios
- Alterar permissões
- Executar comandos externos
- Modificar configurações de produção

## Regra principal
A memória AndreOS guarda decisões, contexto, arquitetura e histórico. Não guarda segredos.
