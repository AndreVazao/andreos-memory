# Stack Padrão

## Preferências gerais
- Android para apps móveis.
- GitHub para versionamento.
- Vercel quando aplicável a dashboards web.
- SQLite para base local.
- PostgreSQL para centralização futura.
- Markdown para memória humana legível.
- Obsidian como interface de memória.
- APIs e conectores para automação.

## Filosofia
- Começar simples e funcional.
- Preparar arquitetura para crescer.
- Evitar dependências desnecessárias.
- Priorizar automação controlada.
