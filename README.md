# AndreOS Memory

Repositório privado de memória persistente do ecossistema AndréOS.

Este repo funciona como ponte entre:

- Obsidian
- ChatGPT
- God Mode
- GitHub
- Projetos pessoais e empresariais

## Vault principal

O vault Obsidian fica em:

```text
AndreOS/
```

## Uso principal

Este repositório guarda memória em Markdown, organizada por projetos, para permitir continuidade entre sessões de IA.

## Projetos iniciais

- GOD_MODE
- PROVENTIL
- VERBAFORGE
- BOT_LORDS_MOBILE
- ECU_REPRO
- BUILD_CONTROL_CENTER

## Regra crítica de segurança

Não guardar aqui passwords, tokens, chaves API, cookies, chaves privadas, credenciais de clientes ou dados bancários sensíveis.

## Como usar comigo

Quando quiseres que eu use esta memória, escreve:

```text
Usa a memória AndreOS no repo AndreVazao/andreos-memory antes de responder.
Projeto: GOD_MODE.
Pedido: ...
```
